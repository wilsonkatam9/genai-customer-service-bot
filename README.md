# GenAI Customer Service Bot 🤖

An AI-powered customer service chatbot built with Google Gemini and Streamlit.

## Features
- 💬 Customer Service Chat (FAQ-based)
- ➕ Dynamic Knowledge Base Update
- 🖼️ Multi-modal Image Q&A
- 🏥 Medical Q&A Bot
- 📚 Research Paper Assistant
- 😊 Sentiment Analysis
- 🌍 Multilingual Support (8 languages)

## Tech Stack
- Python
- Google Gemini 2.5 Flash API
- Streamlit
- Pandas
- LangChain

## Setup
1. Clone the repo
2. Install dependencies: `pip install -r requirements.txt`
3. Create `.env` file with `GOOGLE_API_KEY=your_key`
4. Run: `streamlit run main.py`
